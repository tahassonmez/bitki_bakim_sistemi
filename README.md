# Bitki Bakım Takip Sistemi

Peyzaj/bitki bakım ekipleri için müşteri, bitki ve bakım takip sistemi.

## Klasör yapısı

- pps/api — NestJS backend (@hr/api)
- pps/web — Nuxt frontend (@hr/web)
- docs — 20 günlük uygulama rehberi ve mimari dokümanlar

## Kurulum

```bash
pnpm install
docker compose up -d
```

Detaylı günlük rehber için docs/README.md dosyasına bakın.
